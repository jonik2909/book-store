# Javhar Book Store App

**A role-based Flutter application for managing and reading digital books, with authentication, multi-language support, and admin/author panels.**

---

## 📖 Overview

**Book Store App** is a role-based Flutter application connected to a **backend server**.  
It allows users to **browse, like, and read books**, authors to **create and manage their books**, and admins to **oversee all platform activities**.  

The app communicates with the backend via **REST API** for secure data management and real-time updates, with **state handled reactively using GetX**.  

---

## ✨ Features

- **Authentication:** Login, register, logout with role-based access (Admin, Author, User)  
- **Browse Books:** View top books, like and save favorites  
- **Book Details & Reading:** Read EPUB books directly using **`epub_view`**  
- **Authors Page:** Explore authors, see their biographies and published books  
- **Events Page:** Discover book-related events  
- **My Page:** Track reading history and manage profile  
- **Language Change:** Switch app language using **`flutter_localizations`** and **`intl`**  
- **Author Panel:** Create, edit, and manage books with input validation  
- **Admin Panel:** Manage users, authors, books, and approve or delete content
